 
## Tic for Twitch
quality-of-life tools to Twitch.

## Features

- Video popout and picture-in-picture
- Bitrate and latency display
- Turn lights off on the player
- Custom skin (hex color swap for Twitch purple)
- Auto claim drops
- Hide extensions
- Compact chat
- Minor UI overhaul and clean-up

## Usage

Open any Twitch page, click the Tic for Twitch icon, and toggle the settings you want. Settings are saved and apply on Twitch automatically.
